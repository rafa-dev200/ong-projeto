# Associação Santo André — Plataforma Web

Projeto desenvolvido por **Rafael de Souza** como parte da disciplina **Web Front-End**.

---

##  Descrição Geral
Plataforma completa e responsiva criada para apresentar informações institucionais da ONG **Associação Santo André**, seus projetos sociais e um formulário funcional para voluntários e doadores.

A entrega inclui HTML, CSS e JavaScript, com foco em:

- Boas práticas de código  
- Responsividade  
- Acessibilidade  
- Interatividade  
- Organização de projeto

##  Evolução do Projeto

| Etapa | Conteúdo Desenvolvido | Descrição |
|-------|------------------------|-----------|
| **Entrega I** | HTML5 | Estrutura semântica completa com as páginas: Início, Projetos e Cadastro. |
| **Entrega II** | CSS3 | Estilos modernos, layout responsivo com Flexbox e Grid, paleta de cores e tipografia. |
| **Entrega III** | JavaScript | Interatividade, validação de formulário, menu hambúrguer e dark mode. |
| **Entrega IV** | Acessibilidade + Deploy | Navegação por teclado, melhorias de contraste, textos alternativos e publicação no GitHub Pages. |

---

##  Tecnologias Utilizadas
- **HTML5** — Estrutura semântica  
- **CSS3** — Grid, Flexbox, responsividade, design system  
- **JavaScript (ES6)** — Manipulação do DOM, eventos, validações  
- **Git e GitHub** — Versionamento e deploy  

---

##  Acessibilidade
Implementações realizadas:

- Navegação completa via teclado  
- Textos alternativos em todas as imagens  
- Contraste adequado (padrão WCAG 2.1 AA)  
- Suporte básico para leitores de tela  
- Modo escuro (dark mode) para conforto visual
