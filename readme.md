# Entrega II — HTML + CSS (Layout e Estilos)  
Projeto da disciplina **Web Front-End**  
Segunda etapa: aplicação de CSS responsivo e criação da interface visual do site.

---

## 🎯 Objetivo da Atividade
Transformar o HTML semântico da Entrega I em uma **interface completa**, moderna e responsiva, utilizando **CSS3**, sistemas de layout e boas práticas de design.

---

## ✅ Requisitos Atendidos

### ✔ Design System
Inclui:

- **Paleta de 8 cores** aplicada em fundos, textos, bordas e componentes  
- **Tipografia hierárquica** com 5 tamanhos de fonte  
- **Escala de espaçamento modular**  
  (8px, 16px, 24px, 32px, 48px, 64px)

---

### ✔ Layout Responsivo

Implementado utilizando:

- **Grid de 12 colunas**  
- **Flexbox** para componentes internos  
- **5 breakpoints**, garantindo adaptação para:  
  - Mobile pequeno  
  - Mobile grande  
  - Tablet  
  - Desktop  
  - Wide screen  

---

### ✔ Navegação

- **Menu principal estilizado**  
- **Menu hambúrguer responsivo** funcionando em telas menores  
- Comportamento interativo utilizando apenas CSS/JS simples  

---

### ✔ Componentes Criados

- **Cards de projetos**, usando Grid e sombras  
- **Botões estilizados** com estados:  
  - `hover`  
  - `focus`  
  - `active`  
- **Formulário estilizado** com campos, rótulos, espaçamento e destaque visual

---

### ✔ Imagens incluídas no layout
As imagens foram utilizadas como banner, ilustrações e conteúdo interno, respeitando responsividade e proporção.
