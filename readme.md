# Entrega I — Estrutura HTML Semântica  
Projeto da disciplina **Web Front-End**  
Construção da base estrutural do site utilizando HTML5, aplicando semântica e acessibilidade.

--

##  Requisitos Atendidos

###  Estrutura semântica completa
Uso correto dos principais elementos do HTML5:
- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`

###  Hierarquia correta de títulos  
Aplicação adequada de:
- `h1` — Título principal  
- `h2` — Seções internas  
- `h3` — Subtítulos quando necessário  

###  Criação das 3 páginas obrigatórias

#### **1) index.html — Página institucional**
Inclui:
- Apresentação da ONG  
- Quem Somos  
- Missão, Visão e Valores  
- Imagem de destaque  
- Estrutura semântica organizada  

#### **2) projetos.html — Lista de projetos sociais**
Inclui:
- Título principal  
- Lista de projetos com títulos e descrições  
- Estrutura dividida em seções  

#### **3) cadastro.html — Formulário de voluntários/doadores**
Campos exigidos pela atividade:
- Nome  
- E-mail  
- CPF  
- Telefone  
- Data de nascimento  
- CEP  
- Endereço  
- Cidade  
- Estado (select)  

###  Imagens inseridas na estrutura (sem estilização)
Imagens foram adicionadas apenas com `<img>`, conforme solicitado.
